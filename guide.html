Guide d'utilisation

Comment utiliser la plateforme, même avec peu de données

الرئيسية — Accueil القرآن — Coran poular

1. Suivre une leçon

Sur la page d'accueil, appuyez sur « Ouvrir » sous la leçon choisie. La leçon s'affiche immédiatement : elle ne contient que du texte, aucune image lourde.

2. Télécharger pour lire hors connexion

Appuyez sur « ⬇ Télécharger » : la leçon est enregistrée sur votre téléphone. Vous pouvez ensuite la lire sans connexion Internet, et la partager par Bluetooth ou WhatsApp (fichier de 2 à 4 Ko seulement).

3. Mode hors-ligne automatique

Sur la page d'accueil, appuyez une seule fois sur « Activer le mode hors-ligne ». Toutes les leçons sont mémorisées : les visites suivantes ne consomment plus aucune donnée.

4. Économiser vos données

  • Le site complet pèse moins de 20 Ko — moins d'une photo.
  • Aucune vidéo, aucune police externe, aucune publicité.
  • Chaque leçon téléchargée peut être redistribuée hors-ligne à d'autres élèves.

5. Pour les enseignants : ajouter une leçon

Chaque leçon est un fichier HTML simple. Copiez lecons/lecon-02.html, modifiez le titre, le contenu et les exercices avec n'importe quel éditeur de texte, enregistrez-le sous un nouveau nom, puis ajoutez un lien sur la page d'accueil. Voir le README pour le détail.
