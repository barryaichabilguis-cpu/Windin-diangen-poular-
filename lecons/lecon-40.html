Leçon 4 : وِنْدَنْدِ 4

لِمِن كَدِي : comptons encore

نَاتَنِن تِيمِدِّ اِ اُجُنَّاجِ : entamons les centaines et les milliers.

تِيمِدِرِ : 100

تِيمِدِّ طِطِ : 200

تِيمِدِّ تَتِ : 300

تِيمِدِّ نَيِ : 400

تِيمِدِّ جُيِ : 500

تِيمِدِّ جِيگُم : 600

تِيمِدِّ جِيطِطِ : 700

تِيمِدِّ جِيتَتِ : 800

تِيمِدِّ جِينَيْ : 900

Ex. : تِيمِدِرِ اِ ݖَپَّنطِ تَتِ اِ جِيطِطِ : 137 ; تِيمِدِّ طِطِ اِ ݖَپَّنطِ نَيِ اِ تَتِ : 243 ; تِيمِدِّ تَتِ اِ ݖَپَّنطِ جُيِ اِ گُو : 351 ; تِيمِدِّ جِينَيْ اِ ݖَپَّنطِ جِينَيْ اِ جِينَيْ : 999.

Milliers : اُجُنِرِ : 1000 ; اُجُنَّاجِ طِطِ : 2000 ; اُجُنَّاجِ تَتِ : 3000 ; اُجُنَّاجِ نَيِ : 4000 ; اُجُنَّاجِ جُيِ : 5000 ; اُجُنَّاجِ جِيگُم : 6000 ; اُجُنَّاجِ جِيطِطِ : 7000 ; اُجُنَّاجِ جِيتَتِ : 8000 ; اُجُنَّاجِ جِينَيْ : 9000.

Ex. : اُجُنِرِ اِ تِيمِدِّ جِيگُم اِ ݖَپَّنطِ تَتِ اِ جِيتَتِ : 1638 ; اُجُنَّاجِ نَيِ اِ تِيمِدِّ طِطِ اِ سَپُّ اِ جِيطِطِ : 4217.

Remarque : تِسْكُ : pour compter quelque chose en پُلَار, le mot à compter peut venir avant ou après. Ex. : تِيمِدِّ تَتِ هُورࣹ ou كُيࣹ تِيمِدِّ تَتِ : deux cents têtes.

Leçon 5 : وِنْدَنْدِ 5

Les membres de la famille :

بَابَ / بَابِرَاࢠِ : père

نِينِ / نِينِرَاࢠِ ou يُمَّ / يُمِّرَاࢠِ : mère

ࢠِطُّ / ࢠِࢠِّ ou ࢠِيّ : enfant

مَامَ / مَامِرَاࢠِ ou تَانُو / تَانِرَاࢠِ : grand-père ou grand-mère

كَاوْ / كَاوِرَاࢠِ : oncle

گُگُّ ou گُرْگُل / گُرْگِلَاࢠِ : tante

بَاطِرَاطُ / وَاطِرَاࢠِ : neveu ou nièce

مِݧِرَاطُ / مِݧِرَاࢠِ : petit frère ou petite sœur

مَوْنِرَاطُ / مَوْنِرَاࢠِ : grand frère ou grande sœur

اِسِرَاطُ / اِسِرَاࢠِ : beau-père, belle-mère, beau-frère, belle-sœur

كِينِرَاطُ / كِينِرَاࢠِ : gendre

اَفُ : aîné(e)

كُدُّ : cadet(te)

Remarque تِسْكُ : on ne dira pas تَانُ مَكُّ mais تَانِيكُو : son grand-père ; تَانِيࢠِ : leurs grands-pères. Valable pour : تَانِيكُو/ِيࢠِ، ࢠِيِيكُو/ِيࢠِ، مَوْنِيكُو/ِيࢠِ، مِݧِيكُو/ِيࢠِ، بَاطِيكُو/ِيࢠِ، اِسِيكُو/ِيࢠِ، كِينِيكُو/ِيࢠِ.

Leçon 8 : وِنْدَنْدِ 8

LES SALUTATIONS : سَلْمِنَانْگُ

Le matin : جَم وَالِي / جَم نْبَال-طُن → اَ فِنِي؟ / اُن پِنِي؟ → جَم تَنْ

Vers midi : جَم وِيتِي / جَم نْبِيت-طُن → جَم تَنْ / اِن نْجِتِّي اَللّٰه

Après-midi : جَم ݧَلِّ / جَم ݧَل-طُن → جَم تَنْ

Le soir : جَم هِيرِي / جَم كِير-طُن → اَ هِيرِي اِ جَم / اُن كِيرِي اِ جَم / جَم تَنْ

نُ گَلِّ اُو : et la maison ? → اِنَ اِ جَم

نُ ࢠِسْنْگُ نْگُو : et la famille ? → اِࢠِ اِ جَم

نُ جَوْكَل كَل : et le bien ? → اِنَ اِ جَم

نُ ࢠَنْدُ نْدُو : et la santé ? → كُ مَوْطُمْ

نُ … وَطِي : comment va … ? → اُومُ اِ جَم

كُ مَوْ طُمْ : ça va mieux

اِطِن نْجِتَّ اَللّٰه : nous remercions Allah

نُ نْبَط-طَا / نُ نْبَط-طُن : comment vas-tu / allez-vous ?

اَطَ سِلِّ / اُطُن ݖِلِّ : tu te portes bien / vous vous portez bien

نُ نْبَط-طَا اِ تَمْپِرِ / نُ نْبَطْدُ-طُن اِ تَمْپِرِ : et la fatigue ?

نُ گُلِّ طِي : et les activités ?
