GRAMMAIRE

Leçon 1 : وِنْدَنْدِ 1

L’alphabet : اَلْكُلِ

L’alphabet : اَلْكُلِ ; API et IAI. Le پُلَار utilise ces deux alphabets.

Les 37 lettres sont divisées en :

1 – Voyelles : وُوْيِلِّ

Voyelles courtes : َ ِ ُ ٝ ࣹ

Voyelles longues : َا ِي ُو ٝو ࣹي

Ex. : هَرْدِ / ronfler et هَارْدِ / être rassasié ; هِرْدِ / être jaloux et هِيرْدِ / soirée ; هُرْدِ / tarir et هُورْدِ / jeûner ; سِلْدِ / dévier et سِيلْدِ / hacher la viande ; تُفَادِ / se faire trouer les oreilles et تُوفَادِ / tendre un piège.

2 – Consonnes simples : ب ࢠ ݖ د ط ف گ ه ج ك ل پ ق ر س ت و ي ڃ

ݖَام ; جَلُّ ; گِتِ ; گِسِ.

Lettres spécifiques : ط comme طِطِ ; ࢠ comme ࢠِطُّ ; ݝ comme ݝَرِ ; ڃ comme ڃَمَل ; ݧ comme ݧَامْدِ.

3 – Nasales : م ن ݧ ݝ

4 – Pré-nasales : نب comme نْبَبَّ ; ند comme نْدُوندِي ; نج comme نْجَمْنْدِ ; نگ comme نْگَلُ.

La glottale ء : جِيَل / propriété, parfois جِءَل ; اُولُءُولُوگُ ; هُونْدِ / beugler ou quelque chose ; هُونْءْدِ / sans confusion.

Leçon 2 : وِنْدَنْدِ 2

LES ADJECTIFS POSSESSIFS : سِفَاء جِيَل

اَم : mon, ma — هُورࣹ اَم

مَا : ton, ta — هُورࣹ مَا

مَكُّ : son, sa — هُورࣹ مَكُّ

مِن : notre, nos inclusif — نِينِ مِن

اَمِن : notre, nos exclusif — نِينِ اَمِن

مُن : votre, vos — كَاوْ مُن

مَࢠِّ : leur, leurs — كَاوْ مَࢠِّ

Récapitulation : اَم، مَا، مَكُّ، مِن، اَمِن، مُن، مَࢠِّ

Leçon 3 : وِنْدَنْدِ 3

LA GEMINATION ou سِدُّ

سِدُّ : renforcement d’une articulation consonantique.

Ex. : جُبُّل / جُبِّ ; دَࢠُّ ; لَݖِّرِي / لَݖِّيجِ ; لَدِّ ; لِطِّ ; گُگُّ ; بَجُّ ; لِكِّ ; پُلُّ ; لَمِّ ; اِنَّ ; سِݧُّدِ ; كَقِّ ; لَپُّلَپِّ ; سَقَّ ; هَوَّا ; لَيَّ ; لِڃِّ.

Dans le پُلَار du فُوتَ تُورُ, cinq consonnes ne doublent pas : ر، س، ف، ه، ء.

Ex. : جَلُ / la houe ; جَلُّ / nom de famille ; كُطُ / un étranger ; كُطُّ / un habitant ; گِتِ / yeux ; گِتِّ / coupe-ongle ; بَگِ / tissu ; بَگِّ / qui ne sont pas mûrs.

Pré-nasales géminées : ننب-نند-ننج-ننگ ; ex. : جُنْگُ ; هَنْدِ ; سَنْجُ ; دِنْبَ.

Leçon 4 : وِنْدَنْدِ 4

Les pronoms personnels sujets : لُمْتُوجِ اِنْدِ گُلُّوْوُ

مِ : je ; اَ : tu ; اُ : il/elle

مِن : nous exclusif ; اِن : nous inclusif ; اُن : vous ; ࢠِ : ils/elles

Présent : مِطُ / نْبِطَ / نْبُطُ : je ; اَطَ : tu ; اُومُ : il/elle ; اِمِن : nous exclusif ; اِطِن : nous inclusif ; اُطُن : vous ; اِࢠِ : ils/elles.

Progressif : مِطُنِي / نْبِطَنِي / نْبُطُنِي ; اَطَنِي ; اُومُنِي ; اِمِنِي ; اِطِنِي ; اُطُنِي ; اِࢠِنِي.

Leçon 5 : وِنْدَنْدِ 5

L’alternance consonantique

Lettres qui ne changent pas : ࢠ، ط، ل، م، ن، ݧ، ݝ، ق، ت، ڃ

لَانَ : la pirogue — لَاطِ، لَانِل، لَانَل، لَانِرِي، لَانُرُ، لَاكُن، لَاطِيجِ

ݧَامْدِ : مِطُ ݧَامَ، اَطَ ݧَامَ، اُومُ ݧَامَ، اِمِن ݧَامَ، اِطِن ݧَامَ، اُطُن ݧَامَ، اِࢠِ ݧَامَ.

Consonnes qui changent une fois : ݖ→س ; ف→پ ; ه→ك

سُودُ → ݖُوطِ، ݖُورِل، ݖُورَل ; مِطُ فِجَ → اِمِن پِجَ ; هُطُ → كُطُولِي.

Consonnes qui changent deux fois : ر→د→ند ; ي→ج→نج ; ي→گ→نگ ; و→ب→نب ; و→گ→نگ

رَوَانْدُ → دَوَاطِ → نْدَوْكُن ; يَهْرِ → جَهِن → نْجَهُن ; يِتِرِ → گِتِ → نْگِتُن ; وَانْدُ → بَاطِ → نْبَاكُن ; وُرُ → گُرِ → نْگُرُن.

Leçon 6 : وِنْدَنْدِ 6

LES CLASSES NOMINALES : پِلِّ اِنطِ

Classes : اُو، ࢠِي، نْگُو، نْگِي، نْگَل، نْگِل، نْگُل، نْگُو، كَل، كُن، بَا، كِي، كَا، كُو، نْدِي، نْدِي، نْدُو، طَم، طِي، طِي، طُمْ…

اُو : humains, pluriel ࢠِي ; emprunts. Ex. : اُو مُنْتُور : cette montre.

نْگُو : نْگُو مَايُو : ce fleuve ; نْگُو لِيسُ : cette natte.

نْدِي : نْدِي هُورࣹ : cette tête ; نْدِي لُوندِ : ce canari.

نْدِي : masses : لَݖِّرِي نْدِي ; نْدِي گَوْرِي.

نْگُل : longueur : نْگُل لَاوُل : ce chemin ; نْگُل ࢠُگُّل : cette corde.

نْگِل : diminutif : نْگِل كُيِل : cette petite tête ; نْگِل دِفْتِل.

نْگِي : sept mots : لِيگِ، نَگِّ، هِيگِ، يَنْگِ، نَاݝِ، تُوݧَنْگِ، هَرِ.

طَم : fluides : ڃِيڃَم، نْدِيَم، كُسَم.

طُمْ : classe neutre.

نْدُو : creux : وُيْنْدُ، وِينْدُ.

Pluriel : طِي، طِي، كُن / كُݧ، ࢠِي.

Leçon 7 : وِنْدَنْدِ 7

ݖِيكِرطِ

اِر- اُر- اَنْ- تُ- دُ- اُنْدِر- كِنْد- اُتِر، اُي، اِن

Ex. : هَالْدِ / parler

هَالَنْدِ : raconter à

هَالْدُدِ : parler avec

هَالْتُدِ : reparler / raconter un secret

هَالُرْدِ : profiter d’une occasion pour raconter

هَالِرْدِ : parler comme

هَالُيْدِ : aller raconter

هَالْكِنْدَادِ : faire semblant de parler.

تُ : répétition ; دُ : rapport entre une personne et… ; كِنْد : faire semblant ; اُي : déplacement ; اُر : occasion ; اِر : manière.

Pour la 2e et 3e forme : تُ → ت ; دُ → د.

لِلَادِ : se coucher ; لِلْتَادِ : se recoucher ; لِلْدَادِ : coucher avec ; لِلْكِنْدَادِ : faire semblant de se coucher.

Leçon 8 : وِنْدَنْدِ 8

ݖِيكِرطِ (suite)

Combinaisons : اَنْ + اُر = اَنُر : هَالَنُرْدِ ; اَنْ + اُي = اَنُي : هَالَنُيْدِ ; اَنْ + اِر = اَنِر : هَالَنِرْدِ ; تُ + اَنْ = تَنْ : هَالْتَانْدِ ; دُ + اَنْ + اِر = دَنِر : هَالْدَنِرْدِ ; دُ + اِر + اَنْ = دِرَانْدِ : هَالْدِرَانْدِ ; كِنْد + اُر = كِنْدُر : هَالْكِنْدُرَادِ.

Leçon 9 : وِنْدَنْدِ 9

LES PRONOMS PERSONNELS COMPLÉMENTS : لُمْتُ اِنْدِ تِمُّودِ

كَم : اُ فِيِي كَم : il m’a frappé

مَ : مِ رُكِّي مَ : je t’ai donné

مُ : اَ وَارِي مُ : tu l’as tué

مِن : اُن كَلْجِنِي مِن : vous nous dérangez

اِن : ࢠِ نَامْنِيمَ اِن : ils nous ont demandé

اُن : مِن ݖَلِمِنِي اُن : nous vous avons salués

ࢠِ : اُ تِنْتِنِي ࢠِ : il les a informés.

Leçon 10 : وِنْدَنْدِ 10

LES MOTS INTERROGATIFS

هُل نْدِ : quand — هُل نْدِ اَمَدُ يَهِي؟

مَنْدِ : quand — مَنْدِ اَمَدُ يَهِي؟

هُلِي : qui — هُلِي بِيتِيطُ سَمْبَ؟ ; هُلِي اُون؟

نُ فُتِي : combien — نُ فُتِي كُيْنْگَل نْبَالُ نْگُو جَرِي؟

هُل تُ : où — هُل تُ پَطِ مَا نْگُونِي؟

هُل كُ وَطِي : pourquoi — هُل كُ وَطِي اُ وِيِي نُوْن؟

هُل سَبَابُ : pourquoi

هُل نُ : comment — هُل نُ هَرِ نْدِي گَسِرِي؟

هُل طُوم : quoi / qu’est-ce que.
