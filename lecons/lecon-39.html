CONJUGAISON

Conventions de transcription : ɗ = ط, c = ݖ, ɓ = ࢠ, ƴ = ڃ, mb = نب ; voyelles : َ = a, ࣹ = e, ِ = i, ٝ = o, ُ = u ; ّ = doublement ; ْ = sukun. Le poular est écrit exclusivement en ajami harmonisé.

Leçon 1 : وِنْدَنْدِ 1

Les formes verbales

  • En پُلَار du فُوتَ تُورُ، nous pouvons compter trois formes verbales.
  • Pour toutes ces trois formes verbales, la marque de l’infinitif est : دِ.
  • Il y a les verbes en :
  • Racine plus دِ ; cette forme a la même valeur que la forme en :
  • racine plus ُ plus دِ.

Dans cette catégorie, nous avons des verbes tels que :

  • يَهْدِ : aller, partir
  • اَرْدِ : venir
  • دُگْدِ : courir, fuir
  • دِوْدِ : voler comme l’oiseau
  • اَدُّدِ : amener
  • تُوْدِ : porter sur les épaules
  • لِمْدِ : compter
  • هِلْدِ : casser
  • جُطْدِ : cuir
  • فَهْدِ : renifler
  • هَرْدِ : ronfler
  • لَپُّدِ ou فِيدِ : frapper
  • ݧَامْدِ : manger
  • يَرْدِ : boire
  • تُنْگُدِ : attacher
  • نَنْگُدِ ou جَگُّدِ : attraper

Ces verbes se conjuguent de la même manière. La deuxième forme verbale est celle composée de : Racine plus َا plus دِ.

Leçon 2 : وِنْدَنْدِ 2

Pour les verbes de forme racine plus دِ, l’impératif se présente ainsi :

Avec la deuxième personne du singulier, il suffit d’éliminer la marque de l’infinitif.

Ex. :

  • اَرْدِ → اَرْ : venir → viens
  • يَلْتُدِ → يَلْتُ : sortir → sors
  • لِمْدِ → لِم : compter → compte

Pour la deuxième personne du pluriel, on ajoute ـِن à la racine.

Ex. : لِمْدِ → لِمِن ; يَهْدِ → نْجَهِن ; تُتُّدِ → تُتِّن.

Pour la troisième personne du pluriel, on ajoute ـِي à la racine.

Ex. : لِمْدِ → لِمِي ; يَهْدِ → نْجَهِي.

Ainsi :

لِم / لِمِن / لِمِي

يَهْ / نْجَهِن / نْجَهِي

Pour la deuxième forme verbale, racine plus َا plus دِ, l’impératif se construit ainsi :

2e pers. sing. : on ajoute ـُ à la racine.

Ex. : اُمَّادِ / se lever → اُمُّ / lève-toi ; طَانَادِ / dormir → طَانُ / dors.

2e pers. pl. : on ajoute ـطِن.

Ex. : ݧَاگَادِ / demander → ݧَاگُطِن / demandons.

3e pers. pl. : on ajoute ـطِي.

Ex. : تِلَّادِ / descendre → تِلُطِي / descendez.

Ainsi :

تِلُ / تِلُطِن / تِلُطِي

ݧَاگُ / ݧَاگُطِن / ݧَاگُطِي

Leçon 3 : وِنْدَنْدِ 3

Le présent : سَهَا گُنَاطُ

Pour conjuguer un verbe au présent, il est important de se rappeler des trois formes verbales.

Pour les verbes de la forme racine plus دِ, le présent se construit ainsi : racine plus َ.

Exemple : يَهْدِ / partir

مِطُ يَهَ، مِطُنِي يَهَ

اَطَ يَهَ، اَطَنِي يَهَ

اُومُ يَهَ، اُومُنِي يَهَ

اِمِن نْجَهَ، اِمِنِي نْجَهَ

اِطِن نْجَهَ، اِطِنِي نْجَهَ

اُطُن نْجَهَ، اُطُنِي نْجَهَ

اِࢠِ نْجَهَ، اِࢠِنِي نْجَهَ

Applique cette règle avec : مُݧْدِ / patienter ; نَنْگُدِ / attraper.

Pour les verbes de la forme racine plus َا plus دِ, le présent se présente ainsi : racine plus ُو.

Exemple : لِلَادِ / se coucher

مِطُ لِلُو

اَطَ لِلُو

اُومُ لِلُو

اِمِن لِلُو

اِطِن لِلُو

اُطُن لِلُو

اِࢠِ لِلُو

Applique cette règle avec : جَࢠَّادِ / accueillir ; هُنَادِ / promettre.

Pour la forme racine plus ِي plus دِ, on construit le présent ainsi : racine plus ِي.

Leçon 4 : وِنْدَنْدِ 4

Le passé : سَهَا ࢠِنُّطُ

Il existe cinq types de passé en پُلَار. Pour cette leçon, nous allons nous intéresser au سَهَا ࢠِنُّطُ qui correspond au passé composé français.

Pour la première forme, racine plus دِ, ce type de passé se construit ainsi : racine plus ِي.

Exemple : اُنْدِ / piler

مِ اُنِي

اَ اُنِي

اُ اُنِي

مِن اُنِي ou مِن نْگُنِي

اِن اُنِي ou اِن نْگُنِي

اُن اُنِي ou اُن نْگُنِي

ࢠِ اُنِي ou ࢠِ نْگُنِي

Remarque : le نْگ est de l’alternance consonantique.

تِنْدُدِ / conter

مِ تِنْدِي

اَ تِنْدِي

اُ تِنْدِي

مِن تِنْدِي

اِن تِنْدِي

اُن تِنْدِي

ࢠِ تِنْدِي

Pour la deuxième forme, racine plus َا plus دِ, ce type de passé se construit ainsi : racine plus ِيمَ.

Leçon 5 : وِنْدَنْدِ 5

LE FUTUR PROCHE

On construit le futur proche de deux manières. Dans la première, on met مَ devant les pronoms personnels sujets.

Pour les verbes du groupe 1, racine + دِ, la conjugaison se fait ainsi : مَ + pronom + racine.

دُگْدِ / courir

مَ مِ دُگ

مَ اَ دُگ / مَا دُگ

مَ اُ دُگ / مُو دُگ

مَ مِن نْدُگ

مَ اِن نْدُگ / مِن نْدُگ

مَ اُن نْدُگ / مُن نْدُگ

مَ ࢠِ نْدُگ

Pour les verbes du groupe 2, racine + َا + دِ, la conjugaison se fait ainsi : racine + ُ.

لِلَادِ / se coucher

مَ مِ لِلُو

مَ اَ لِلُو / مَا لِلُو

مَ اُ لِلُو / مُو لِلُو

مَ مِن لِلُو

مَ اِن لِلُو / مِن لِلُو

مَ اُن لِلُو / مُن لِلُو

مَ ࢠِ لِلُو

Pour le groupe 3, racine + ِي + دِ, la conjugaison se fait ainsi : racine + ِ.

هَࢠِيدِ / se battre

مَ مِ هَࢠِ

مَ اَ هَࢠِ ou مَا هَࢠِ

مَ اُ هَࢠِ ou مُو هَࢠِ

مَ مِن كَࢠِ

مَ اِن كَࢠِ ou مِن كَࢠِ

مَ اُن كَࢠِ ou مُن كَࢠِ

مَ ࢠِ كَࢠِ
