Connectez-vous avec un jeton d'accès personnel GitHub (fine-grained) autorisé sur le dépôt Windin-diangen-poular- avec la permission Contenus : lecture et écriture. Le jeton reste uniquement dans votre navigateur : il n'est jamais enregistré sur le site ni envoyé ailleurs que sur api.github.com.

Créer un jeton : GitHub → Settings → Developer settings → Fine-grained personal access tokens → « Repository access : only Windin-diangen-poular- » → Permissions → Contents : Read and write.
